The separation that makes BeneBot honest

02

The AI never does the arithmetic

Application code accepts only known EOB categories, normalizes USD values, checks three equations within one cent, and produces a ready-to-speak summary. The language model may explain that summary. It may not derive missing money.

Allowed 2,400 − 1,300 = 1,100 ✓
Patient responsibility 500 + 0 + 120 + 0 = 620 ✓
Insurer paid 1,100 − 620 = 480 ✓
✓
Reconciled to $0.01

Numerical explanation is permitted.

03

Determinism applied to the AI chain

BeneBot gives generation a narrow job: patient-friendly language. Identity, tool order, financial facts, source dates, action success, and safe fallback behavior stay in code.

  1. 01 Scope

    A short-lived JWT binds one patient, bill, EOB, coverage, encounter, provider, and payer.

  2. 02 Normalize

    Zod and FHIR-aware code accept known structures and preserve missing values as unknown.

  3. 03 Reconcile

    Pure functions prove the three bill equations before exact amounts can reach conversation.

  4. 04 Explain

    Deepgram receives approved concepts and deterministic summaries, then speaks naturally in the selected language.

  5. 05 Confirm

    No Task, Communication, payer result, or resource action is described as successful before server proof.

05

Voice that inherits the same safety contract

Deepgram Flux listens in English and Spanish with turn awareness. A bilingual Aura voice answers. The browser gets only a five-minute temporary token, and every function call returns through a signed BeneBot server route.
